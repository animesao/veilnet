# Архитектура veilnet

## Общая идея
veilnet использует TC + eBPF для перехвата исходящего/входящего трафика и применения DPI-bypass стратегий.

## Компоненты
- **eBPF (kernel)**: классификация пакетов, парсинг IP/TCP/TLS, базовые модификации (при возможности)
- **libbpf loader (userspace)**: загрузка, прикрепление к TC, управление maps
- **veilnetd (daemon)**: конфиг, синхронизация правил, статистика
- **veilctl**: CLI для управления

## Карта
TC clsact на интерфейсе -> eBPF программа -> матч по правилам из BPF maps -> применение стратегии (или передача в userspace через ringbuf)

## Почему TC + eBPF
- Меньше копирований чем NFQUEUE
- Работает на уровне сетевого стека, "всегда активно"
- Гибко под интерфейсы, роутинг
- Хороший баланс производительности/безопасности
